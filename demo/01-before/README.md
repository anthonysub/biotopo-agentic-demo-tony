# 01 - Before

Estado base de la demo.

> Antes de este paso, completa [00-cli-y-agentics](../00-cli-y-agentics/README.md) (CLI, Agentics) o el checklist en [demo/README.md](../README.md#prerrequisitos).

Qué mostrar:

- `npm run dev` levanta una landing turística pequeña y funcional en Next.js.
- `npm run validate` pasa sin errores.
- `.github/workflows/validate-site.yml` representa automatización tradicional.
- `.github/workflows/biotopo-pr-review.md` representa el flujo agentico.

Comandos:

```bash
npm install
npm run dev
npm run validate
npm run build
```

Mensaje pedagógico:

> Aquí tenemos un repositorio normal: Next.js, componentes React, una imagen en `public/`, un test pequeño y GitHub Actions.
